# 00. Product Brief

## 1. 제품 정의
**PaperType**(가칭)은 실제 타자기를 모방하는 스킨이 아니라, 디지털 입력을 **아날로그 글쓰기 의식(ritual)** 으로 바꾸는 로컬 우선 글쓰기 앱이다.

### 제품 문장
> “아무 내용이 없어도 앱을 열어 몇 글자 타이핑하고 싶어지는 개인용 디지털 타자기.”

## 2. 주요 사용자
- 짧은 일기·생각 기록을 하는 사용자
- 일반 노트 앱의 복잡함보다 집중형 글쓰기를 원하는 사용자
- 편지, 기도문, 묵상, 창작 문장처럼 결과물의 질감도 중요하게 보는 사용자
- 네트워크/계정 없이 개인 글을 보관하고 싶은 사용자

## 3. Job To Be Done
사용자가 생각을 기록하려는 순간, PaperType은 기능 선택에 시간을 쓰지 않고 **즉시 한 장의 종이와 타이핑 감각**을 제공해야 한다.

## 4. 비목표(Non-goals)
초기 버전에서 다음을 하지 않는다.
- 실시간 협업
- 팀 워크스페이스
- AI 글쓰기 자동완성
- 광고/행동 분석 SDK
- 강제 계정/클라우드
- Notion 수준 블록 편집
- 리치 텍스트 전체 기능

## 5. 제품 우선순위
1. Writing feel
2. Korean IME correctness
3. Local data safety
4. Beautiful output
5. Organization
6. Optional sync (장기)

## 6. MVP 기능 범위
### 반드시 포함
- 노트 생성/열기/삭제/복원
- 자동 저장
- 한글/영문 IME 입력
- 종이 텍스처 3종
- 잉크 프리셋 3종
- 키/스페이스/백스페이스/엔터 사운드
- 고정 타점 + 종이/캐리지 모션
- 라이트/나이트 램프
- IndexedDB 저장
- TXT/MD/JSON Export
- JSON/ZIP Backup
- PWA / Offline

### v1 후속
- PNG/PDF Keepsake
- 장식(압화, 스탬프, 클립 등)
- 사진 스탬프
- A4/A5/Letter
- Android Native

## 7. 성공 지표
서버 분석을 넣지 않는다는 원칙 때문에 앱 자체 telemetry 대신 **개발/테스트 지표**와 사용자 피드백을 사용한다.

### 기술 성공 지표
- IME 조합 입력 오류 재현 0건 (정의된 테스트 케이스 기준)
- 1000자 연속 입력 중 데이터 손실 0건
- autosave 실패 시 사용자에게 복구 가능 상태 제공
- P95 입력→시각 피드백 목표 16ms 이내(지원 환경에서)
- 60Hz 환경에서 애니메이션 평균 55fps 이상을 품질 기준으로 사용

### UX 성공 지표
베타 테스터에게 다음 질문을 5점 척도로 확인한다.
- “입력 자체가 즐겁다.”
- “일반 메모 앱보다 글에 집중된다.”
- “소리/움직임이 방해가 아니라 질감을 만든다.”
- “다시 열어 쓰고 싶다.”

## 8. 플랫폼 전략
### Stage A — Web/PWA
UX와 렌더링 모델을 빠르게 검증한다. 배포 가능한 독립 제품으로 취급한다.

### Stage B — Android Native
웹을 WebView로 감싸지 않는다. Kotlin + Jetpack Compose로 다시 구현하여 햅틱, 파일 공유, Android IME, 오디오 지연을 네이티브 수준으로 끌어올린다.

## 9. 배포 철학
- Web: 정적 호스팅 가능, 서버 의존 없음
- Android: 오프라인 완전 동작, 스토어 여부와 무관하게 APK 배포 가능 구조
- 저장 포맷은 웹/Android 공통 schema version으로 관리
